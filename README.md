# orianaschinocca

Mobile-first personal portfolio (Astro, static output, React islands).

## Run

```
npm install
npm run dev     # http://localhost:4321/?v=1  (also ?v=2, ?v=3)
npm run build
```

## Prototypes (throwaway)

`src/prototype/` holds three radically different designs of the same page,
all fed by `src/content/site.ts` (the only place with copy, Spanish es-AR).
Switch with `?v=1|2|3` or the floating bottom bar.

1. Technical dark (taste reference: linear)
2. Warm editorial (taste reference: anthropic)
3. Bold playful (taste reference: nothing)

After the owner picks one, the others are deleted.
